Why Can't Normal Downloaders Fetch Private Videos Directly?

Social media platforms like Facebook and Instagram utilize strict token-based session authentication. When a user requests a private post, Meta's edge servers inspect the browser's HTTP cookies to verify whether that specific account has permission to view the content:

  • Public Videos: The CDN stream is openly accessible to any web scraper or downloader without cookies.
  • Private Videos: If an automated server requests the video URL, Meta detects the absence of an authorized user session and immediately terminates the connection with a 403 Forbidden or redirects to a login prompt.
  • The Web Browser Advantage: When you open the private post on your web browser while logged into your own account, your browser successfully authenticates with Meta. In response, Meta sends your browser the HTML page source containing the encrypted, temporary high-definition media stream URLs.

Step-by-Step Instructions by Web Browser

Google Chrome & Brave

  1. Log into Facebook or Instagram in Chrome/Brave.
  2. Open the private video post in a tab.
  3. Press Ctrl + U (or Cmd + Option + U on Mac).
  4. A new tab opens showing the HTML source. Press Ctrl + A then Ctrl + C to copy all.
  5. Paste into downsocial and click Extract Private Video.

Microsoft Edge

  1. Open the private video in Edge while logged into your authorized account.
  2. Right-click anywhere on an empty part of the page and select 'View page source' (or press Ctrl + U).
  3. Press Ctrl + A to select all source code, then Ctrl + C.
  4. Paste the code into downsocial's box above to extract your HD video.

Mozilla Firefox

  1. Navigate to the private post in Firefox.
  2. Press Ctrl + U (Mac: Cmd + U) or right-click > 'View Page Source'.
  3. Select all HTML code with Ctrl + A and copy with Ctrl + C.
  4. Paste into the downsocial Private Downloader and download your MP4 file.

Apple Safari (Mac)

  1. In Safari, go to Settings / Preferences > Advanced.
  2. Check the box for 'Show Develop menu in menu bar'.
  3. Navigate to your private Facebook or Instagram video.
  4. Click Develop > Show Page Source (or press Cmd + Option + U).
  5. Copy all HTML and paste into downsocial.

Mobile Web (Android)

  1. Open Chrome or Samsung Internet on your Android device and log into Facebook/Instagram.
  2. Open the private post URL.
  3. Tap the browser address bar, go to the start of the URL, and type view-source: (e.g. view-source:https://www.facebook.com/...).
  4. Tap Enter. The raw code displays. Select all, copy, and paste into downsocial.
